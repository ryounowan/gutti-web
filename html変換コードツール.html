④ Windows用 .exe アプリケーションの作成手順

Electronとelectron-builderを利用して、配布可能な独自の.exeファイルを生成する手順と設定です。

2. package.json (ビルド設定入り)

3. main.js

4. .exe 作成手順コマンド

  1. 空のフォルダを作成し、上記の index.html, package.json, main.js を配置します。
  2. そのフォルダでターミナル（コマンドプロンプト等）を開き、以下を実行して依存関係をインストールします：
    npm install
  3. インストール完了後、以下のコマンドで.exeファイルのビルドを実行します：
    npm run dist
  4. ビルドが成功すると、新しく作られた dist/ フォルダー内に Setup.exe（またはポータブル版exe）が生成されます！

⑥ Android用 .apk アプリケーションの作成手順

モダンなWeb-to-AppフレームワークであるCapacitorを利用し、このHTMLをAndroidアプリ（.apk）にビルドする手順です。

2. capacitor.config.json

3. package.json (Android用)

4. .apk 作成手順コマンド

※PCに Node.js、Android Studio、およびAndroid SDKがインストールされている必要があります。
  1. 作業用フォルダを作成し、上記の package.json を配置して、ターミナルで以下を実行します：
    npm install
  2. フォルダ内に www という名前のフォルダを作り、その中にダウンロードした index.html を配置します。
  3. 同じ場所に上記の capacitor.config.json を配置します。
  4. 以下のコマンドを順番に実行して、Androidプロジェクトを同期・展開します：
    npx cap add android
npx cap sync
  5. 最後にAndroid Studioを起動してプロジェクトを開くか、以下のコマンドで直接Android Studioを立ち上げます：
    npx cap open android
  6. Android Studioが起動したら、上部メニューの Build > Build Bundle(s) / APK(s) > Build APK(s) を選択すると、デバッグ・テスト用の .apk ファイルが自動生成されます！
